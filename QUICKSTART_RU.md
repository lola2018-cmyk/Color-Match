# 🎨 Color Match - Быстрый Старт

## 📌 Что было создано?

## 📋 Что реализовано?

### ✅ Ядро игры
- 🎯 Stroop Effect тест (определение цвета вместо слова)
- 👥 Мультиплеер на 2-4 человека
- ⚡ Реал-тайм синхронизация через WebSocket
- 🏆 Система очков и рейтинга
- 📊 Статистика и лидерборд
- 🔐 Аутентификация пользователей

### ✅ Технологии
- **Frontend**: React 19.2 + Next.js 16 + TypeScript + Tailwind
- **Backend**: Next.js API + tRPC + Socket.IO
- **База данных**: PostgreSQL + Drizzle ORM
- **Тестирование**: Vitest (unit-тесты логики)

### ✅ Готовые страницы/компоненты
1. **Главная страница** (`/`) - Лобби для выбора режима
2. **Выбор курса** (`/select-course`) - Выбор сложности
3. **Игровая сессия** (`/game/[sessionId]`) - Основная игра
4. **Лидерборд** (`/leaderboard`) - Глобальный рейтинг
5. **Статистика** (`/stats`) - Ваша статистика
6. **Вход/Регистрация** (`/login`, `/register`) - Аутентификация

## 💾 Требования для полной функциональности БД

Для работы с БД (опционально для демонстрации):

```bash
# 1. Установить PostgreSQL
# Windows: скачать с https://www.postgresql.org/download/windows/
# Mac: brew install postgresql@14
# Linux: sudo apt-get install postgresql

# 2. Создать БД
createdb color_match

# 3. Обновить .env.local
# Откройте файл: c:\Users\Elizaveta\Desktop\color-match\.env.local
# Установите DATABASE_URL=postgresql://user:password@localhost:5432/color_match

# 4. Развернуть схему
npm run db:push

# 5. Заполнить тестовые данные
npm run db:seed  # (после создания скрипта)
```

**Примечание:** Прямо сейчас приложение работает с mock данными, БД не требуется для тестирования UI/UX.

## 🎮 Как играть

1. **Откройте лобби** (`/`)
2. **Введите имя игрока** и выберите режим (создать или присоединиться)
3. **Выберите курс сложности** (Easy/Medium/Hard)
4. **Играйте!** Определите цвет чернил, игнорируя значение слова
   - 🟢 Правильный ответ → Получите очки
   - ❌ Неправильный ответ → -5 очков и штраф для других
5. **Посмотрите результаты** на экране статистики

## 📊 Система очков

| Действие | Очки |
|---------|------|
| Easy + 1st ответ + макс скорость | ~15 |
| Medium + 2nd ответ + средняя скорость | ~10 |
| Hard + 3rd ответ + медленный | ~7 |
| Неправильный ответ | -5 |
| Штраф (3 сек) | Визуальное размытие |
